Travira Backend — deploy checklist (Render)
==========================================

EMAIL ON RENDER FREE TIER
-------------------------
Render free services BLOCK outbound SMTP (ports 25, 465, 587).
Gmail SMTP will always "Connection timeout".

Use Resend (free tier, HTTPS API):
  1) Sign up https://resend.com
  2) Create API key
  3) On Render set:
       RESEND_API_KEY=re_xxxx
       EMAIL_FROM=Travira <onboarding@resend.dev>
  4) Redeploy
  5) Test: GET /api/health/email  → smtpOk true (provider resend)

  Note: with onboarding@resend.dev you can only send TO your own Resend account email
  until you verify a domain. For production, add a domain in Resend.

Other env:
  MONGODB_URI, JWT_SECRET, JWT_REFRESH_SECRET
  GEMINI_API_KEY, GEMINI_MODEL=gemini-2.5-flash
  APP_BASE_URL=https://travira-app-minor.onrender.com

Start: npm start
