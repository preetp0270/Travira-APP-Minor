Travira Backend — deploy checklist (Render)
==========================================

1) Push the backend folder to the GitHub repo connected to Render.
2) Render → Manual Deploy (wait until green).
3) Environment variables:

   MONGODB_URI=...
   JWT_SECRET=...
   JWT_REFRESH_SECRET=...
   GEMINI_API_KEY=...
   GEMINI_MODEL=gemini-2.5-flash
   APP_BASE_URL=https://travira-app-minor.onrender.com

   EMAIL_HOST=smtp.gmail.com
   EMAIL_PORT=587
   EMAIL_USER=your-email@gmail.com
   EMAIL_PASS=<Gmail App Password 16 chars>
   EMAIL_FROM=Travira <your-email@gmail.com>

   Optional: KEEP_ALIVE_MS=180000

4) After deploy open:
   https://travira-app-minor.onrender.com/api/health
   https://travira-app-minor.onrender.com/admin.html
   https://travira-app-minor.onrender.com/reset-password.html

5) Admin login uses an existing user with role admin or superadmin
   (e.g. him@travira.app). There is no separate root-admin seed.

Start command:  npm start
Node: >= 18
